# دليل تصميم المنتجات الرقمية لمنظومة SINDA

## النطاق

إنشاء منتجات رقمية مترابطة وقابلة للتوسع، مع فصل كل منتج ووظائفه وبياناته وصلاحياته.

## أنواع المنتجات

1. **التطبيقات**: تطبيق ويب متجاوب، وتجهيز لاحق لتطبيقات الهاتف وسطح المكتب عند اعتماد المتطلبات.
2. **المنتديات والمجتمعات**: حسابات أعضاء، ملفات شخصية، مواضيع وردود، تصنيفات، بحث، إبلاغ وإشراف ومكافحة إساءة الاستخدام.
3. **المواقع الإلكترونية**: صفحات تعريفية وتسويقية، صفحات هبوط، مركز مساعدة، ولوحات إدارة المحتوى.
4. **حضور التواصل الاجتماعي**: صفحات تعريف وروابط موحدة، تقويم محتوى، مسودات منشورات، وتحليلات يدوية/مصرح بها. لا تُنشأ الحسابات ولا تُنشر المنشورات تلقائيًا دون موافقة مالك الحساب.
5. **المتاجر الرقمية**: كتالوج منتجات، تصنيفات، بحث، سلة وطلبات تجريبية، إدارة مخزون، ولوحة تاجر. تعطّل بوابات الدفع والتحصيل الفعلي في مرحلة النموذج الأولي.

## مجلدات التصميم

- `design/applications/`
- `design/forums/`
- `design/websites/`
- `design/social-media/`
- `design/digital-stores/`

## معايير التصميم والتنفيذ

- واجهة عربية RTL وإنجليزية LTR مع دعم الجوال وسطح المكتب وإمكانية الوصول.
- نظام تصميم موحد: ألوان، خطوط، مسافات، مكونات، حالات تحميل/خطأ/فراغ.
- فصل الواجهة عن API وقاعدة البيانات، مع توثيق العقود والنسخ.
- مصادقة آمنة، صلاحيات حسب الدور، حماية الجلسات، تحديد المعدل، وسجل تدقيق.
- خصوصية افتراضية: أقل قدر من البيانات، وعدم تضمين أسرار أو بيانات شخصية/مالية حقيقية في المستودع.
- اختبارات واجهة ووحدات وتكامل وأمان قبل طلب المراجعة.

## مراحل التسليم

1. متطلبات ونماذج أولية (wireframes) لكل نوع منتج.
2. نظام التصميم ومكونات الواجهة المشتركة.
3. نموذج تفاعلي ببيانات اصطناعية.
4. ربط API وقاعدة البيانات بعد مراجعة الصلاحيات.
5. اختبارات أمنية ووظيفية وتقرير جاهزية.
6. مراجعة بشرية وموافقة منفصلة قبل أي دمج أو نشر أو تفعيل دفع أو ربط حسابات خارجية.

## حدود النسخة الحالية

هذه وثيقة نطاق وهيكل مجلدات فقط؛ لا تعني أن التطبيقات أو المنتديات أو المواقع أو حسابات التواصل أو المتاجر قد بُنيت أو نُشرت. لا توجد عمليات دفع أو نشر محتوى أو إنشاء حسابات خارجية في هذه المرحلة.
