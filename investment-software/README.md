# Investment Software

مجلد تطوير مستقل لبرمجيات مشروع الاستثمار الذكي ضمن SINDA.

## الوحدات التقنية

- `frontend/`: واجهة المستخدم ولوحات العرض.
- `backend/`: خدمات التطبيق وواجهات API.
- `ai/`: التحليل الذكي ومكونات المساعدة.
- `data/`: بيانات تجريبية غير حساسة فقط.
- `database/`: مخططات قاعدة البيانات والترحيلات.
- `security/`: المصادقة والصلاحيات وسجلات التدقيق.
- `tests/`: اختبارات الوحدات والتكامل والأمان.
- `docs/`: التصميم والتوثيق وتقارير المراجعة.
- `design/`: مواصفات وتصاميم المنتجات الرقمية.

## المنتجات الرقمية المستهدفة

- تطبيقات الويب والجوال وسطح المكتب.
- المنتديات والمجتمعات الرقمية.
- المواقع التعريفية والتسويقية.
- حضور وحسابات التواصل الاجتماعي وإدارة المحتوى.
- المتاجر الرقمية والكتالوجات والطلبات.

راجع [دليل تصميم المنتجات الرقمية](docs/digital-products-design.md) للنطاق والمراحل والضوابط.

## ضوابط العمل

- الهيكل والوثائق لا تعني اكتمال المنتجات أو اتصالها بخدمات خارجية.
- استخدم بيانات اصطناعية/تجريبية فقط. لا تضع مفاتيح API أو كلمات مرور أو بيانات مالية حقيقية في المستودع.
- لا تنشئ حسابات تواصل خارجية ولا تنشر محتوى تلقائيًا دون موافقة صريحة.
- لا تفعّل دفعًا حقيقيًا أو تحصيلًا ماليًا في النموذج الأولي.
- أي تكامل مع أسعار أو محافظ أو شبكات عامة يكون للقراءة فقط في هذه المرحلة.
- لا تنفذ معاملات مالية، ولا تنشر عقودًا أو خدمات إنتاجية.
- اختبر التغييرات على هذا الفرع فقط. لا تدمج إلى `main` ولا تنشر دون موافقة صريحة ومراجعة نهائية.
