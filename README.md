# Sinda Nexus

منظومة ذكية وقابلة للتكوين لإدارة المشاريع والملفات والتقارير، مع واجهة تجريبية لتكامل محفظة EVM خارجية وخدمة أسعار أصول رقمية للقراءة فقط.

## بدء التشغيل

يتطلب Node.js 22 أو أحدث:

```bash
npm ci
npm run check
npm start
```

افتح `http://127.0.0.1:3000/` لواجهة MetaMask التجريبية. يتطلب الربط متصفحًا يدعم محفظة EIP-1193 مثل MetaMask.

## Alchemy Prices API (Preview)

توجد خدمة الأسعار في `src/prices/alchemy.js`، وتُعرض عبر مسارات API للقراءة فقط:

| المسار | الطريقة | الوظيفة |
|---|---|---|
| `/api/prices/by-symbol?symbols=ETH,BTC` | GET | الأسعار الحالية حسب الرمز |
| `/api/prices/by-address` | POST | الأسعار الحالية حسب الشبكة وعنوان العقد |
| `/api/prices/historical` | POST | الأسعار التاريخية حسب الرمز أو عنوان العقد |

### وضع Preview الآمن

الوضع الافتراضي هو `ALCHEMY_PRICES_MODE=mock`. يعيد بيانات تجريبية ثابتة ولا يجري أي اتصال خارجي. لا يحتاج هذا الوضع إلى مفتاح API.

لاختبار طبقة الموفر باستخدام بيانات وهمية في الاختبارات، تُحقن دالة fetch وهمية ولا تُستخدم مفاتيح حقيقية. مسار الاتصال الفعلي موجود لكنه معطّل افتراضيًا؛ يتطلب تفعيله صراحةً `ALCHEMY_PRICES_MODE=alchemy` ومفتاحًا محفوظًا في `ALCHEMY_API_KEY`. لا تضع المفتاح في الواجهة أو المستودع أو سجلات الطلبات.

مثال طلب عنوان عقد:

```bash
curl -X POST http://127.0.0.1:3000/api/prices/by-address \
  -H "Content-Type: application/json" \
  -d '{"addresses":[{"network":"eth-mainnet","address":"0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48"}]}'
```

مثال أسعار تاريخية:

```bash
curl -X POST http://127.0.0.1:3000/api/prices/historical \
  -H "Content-Type: application/json" \
  -d '{"symbol":"ETH","startTime":"2026-01-01T00:00:00Z","endTime":"2026-01-02T00:00:00Z","interval":"1d"}'
```

### ملاحظات

- لا تنفذ خدمة الأسعار أي عمليات تداول أو تحويل أو توقيع.
- بيانات Mock ليست أسعارًا سوقية ولا يجوز استخدامها لاتخاذ قرار مالي.
- يدعم التحقق حتى 25 رمزًا أو عنوانًا في الطلب.
- الفترات التاريخية المقبولة: `1m` و`5m` و`1h` و`1d`.
- يُعاد خطأ موحد عند تجاوز حدود الموفر أو تعطل الاتصال؛ لا تُكشف تفاصيل سرية من الموفر.

## تكامل MetaMask (واجهة تجريبية)

الواجهة في `public/`، ومساعد المحفظة في `src/web3/wallet.js`. يقدّم التطبيق:
- ربط المحفظة بطلب صريح من المستخدم عبر `eth_requestAccounts`.
- عرض الحساب المتصل والاستجابة لتغيير الحساب أو الشبكة.
- تجهيز معاملة EVM محليًا والتحقق من العنوان والقيمة والبيانات وحقول الرسوم.
- شاشة مراجعة أولية قبل فتح تأكيد MetaMask.
- التحقق من chain ID قبل طلب `eth_sendTransaction`.
- التحقق من حالة المعاملة عبر RPC للقراءة فقط.

### شبكات الواجهة

الواجهة التجريبية تعرض شبكات اختبار فقط:
- Ethereum Sepolia — chain ID `11155111`
- BNB Smart Chain Testnet — chain ID `97`
- Polygon Amoy — chain ID `80002`

لا تدخل عبارة الاسترداد أو المفتاح الخاص في الموقع أو الدردشة. لا تستخدم أموالًا حقيقية في الاختبار.

## الأمان والاعتماد

- لا تضع مفاتيح خاصة أو عبارات استرداد أو كلمات مرور أو مفاتيح API في المستودع أو الواجهة.
- اختبارات المحفظة تستخدم مزودًا وهميًا؛ لا توقّع ولا تبث معاملات.
- الدمج في `main` والنشر منفصلان عن هذه المسودة ويتطلبان مراجعة نتائج CI وموافقة صريحة.
