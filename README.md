# Sinda Nexus

منظومة ذكية وقابلة للتكوين لإدارة المشاريع والملفات والتقارير.

## الحالة الحالية

هذا المستودع يحتوي على API أولية لإدارة المشاريع والتقارير. التغييرات الأمنية والتحسينية الحالية موجودة على فرع مراجعة مستقل، ولا تعني أن النظام أصبح جاهزًا للإنتاج.

## المتطلبات والتشغيل

- Node.js 20 أو أحدث.
- تثبيت الاعتماديات: `npm install`.
- نسخ `.env.example` إلى `.env` وتغيير `API_TOKENS` إلى سر عشوائي فريد بطول 32 حرفًا على الأقل. مثال للتوليد محليًا: `openssl rand -hex 32`.
- تشغيل الاختبارات: `npm test`.
- تشغيل فحص الصياغة والاختبارات: `npm run check`.
- تشغيل الخدمة: `npm start`.

لا تضع أي قيمة حقيقية لـ `API_TOKENS` في المستودع أو السجلات أو الواجهة الأمامية. يمكن فصل الرموز المتعددة بفواصل، ويجب إرسال الرمز عبر `Authorization: Bearer <token>`.

## الإعدادات

| المتغير | الافتراضي | الغرض |
|---|---|---|
| `HOST` | `127.0.0.1` | واجهة الاستماع |
| `PORT` | `3000` | منفذ HTTP |
| `API_TOKENS` | غير مضبوط | رموز وصول مشتركة؛ غيابها يغلق API |
| `DATA_FILE` | `./data/projects.json` | ملف تخزين بيانات المشاريع |
| `MAX_PROJECTS` | `1000` | الحد الأقصى لعدد المشاريع |
| `RATE_LIMIT_WINDOW_MS` | `60000` | نافذة تحديد المعدل بالمللي ثانية |
| `RATE_LIMIT_MAX` | `100` | الطلبات المسموح بها لكل نافذة |

يمكن استخدام `:memory:` كخيار تخزين للاختبارات فقط. حد جسم JSON هو 100 KiB. لا يشمل محدد المعدل نقطة `/health`، ويحسب محاولات المصادقة الفاشلة ضمن مسارات API.

## ما تم تحسينه

- فرض مصادقة Bearer على جميع مسارات API، مع رفض الرموز الأقصر من 32 حرفًا.
- تحديد معدل الطلبات قبل المصادقة للحد من تخمين الرموز.
- عدم تخزين استجابات API أو الصحة في Cache.
- التحقق الصارم من الإعدادات والبيانات الواردة والمحفوظة.
- رفض ملف بيانات رمزي (symlink) أو ملف خاص.
- حفظ JSON عبر ملف مؤقت بصلاحيات مقيدة ثم إعادة التسمية الذرية.
- إغلاق خادم HTTP بشكل منظم عند SIGTERM/SIGINT.
- توسيع الاختبارات الأمنية واختبارات الاستمرارية.

## حدود أمنية مهمة

- رمز Bearer المشترك ليس نظام هوية مستخدمين؛ لا توجد أدوار أو ملكية مشروع أو عزل مستأجرين أو تدوير/إلغاء رموز متكامل.
- تخزين JSON مناسب لعملية واحدة وتجارب محدودة فقط، وليس قاعدة بيانات إنتاجية أو بيئة متعددة النسخ.
- محدد المعدل الحالي يستخدم مخزنًا داخل العملية؛ يلزم مخزن مشترك قبل تشغيل عدة نسخ.
- لا توجد سجلات تدقيق غير قابلة للعبث، أو رفع ملفات، أو صلاحيات دقيقة.
- ملف `package-lock.json` لم يُنشأ ويُتحقق منه بعد؛ لذلك لم يكتمل التثبيت القابل لإعادة الإنتاج. لا تعتبر `npm install` بديلًا عن lockfile موثوق.
- يجب انتظار نتائج CI والتدقيق الأمني ومراجعة إعدادات الاستضافة قبل أي إطلاق.

استخدم بيانات اختبار اصطناعية فقط. لا تضع بيانات عملاء أو بيانات مالية أو أسرارًا حقيقية في هذا النموذج. لا يتضمن هذا العمل دمجًا إلى `main` أو نشرًا أو ربطًا ماليًا حقيقيًا.

## نقاط النهاية

- `GET /health` — فحص صحة عام.
- `GET /api/projects` — قائمة المشاريع (يتطلب Bearer token).
- `POST /api/projects` — إنشاء مشروع (يتطلب Bearer token).
- `GET /api/projects/:id` — تفاصيل مشروع (يتطلب Bearer token).
- `GET /api/reports/summary` — ملخص المشاريع (يتطلب Bearer token).
