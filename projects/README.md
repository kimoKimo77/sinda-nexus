# Sinda Nexus Projects

This directory contains isolated project areas for the Sinda Nexus workspace.

## Structure

- `core/` — core application and shared services.
- `smart-contracts/` — smart contracts and contract tooling.
- `blockchain/` — blockchain integrations and read-only adapters.
- `ai-agents/` — AI agents, orchestration, and simulations.
- `security/` — security reviews, policies, and hardening work.
- `tests/` — project-level integration and validation tests.
- `docs/` — project documentation and reports.

Keep credentials, private keys, production data, and generated secrets out of this directory. Add new work on isolated branches and validate it before proposing integration.
