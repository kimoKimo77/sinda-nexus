# SINDA Platform

**مشروع منصة SINDA الموحدة**

## الهدف

هذا المجلد هو نقطة التوثيق الرئيسية لتجميع مكونات منظومة SINDA الرقمية وتحديد حدودها ومسؤولياتها، مع إبقاء كل مكوّن قابلاً للتطوير والاختبار بصورة مستقلة.

## نطاق المنصة

تُرتّب الأعمال ضمن مجالات واضحة، بحسب ما يتم تنفيذه واعتماده فعلياً:

- **Core Services:** الخدمات الأساسية وواجهات API وإدارة الإعدادات.
- **Smart Contracts & Blockchain:** العقود الذكية وتكاملات الشبكات، مع فصل بيئات الاختبار عن أي تشغيل فعلي.
- **AI & Agents:** محركات الذكاء الاصطناعي والوكلاء وأدوات الأتمتة.
- **Investment & Market Data:** بيانات الأسواق والتحليلات الاستثمارية للقراءة والمعاينة.
- **Security & Governance:** المصادقة والصلاحيات وسجلات التدقيق وسياسات الحماية.
- **Testing & Quality:** الاختبارات الآلية والتحقق من التكامل والأداء والأمان.
- **Documentation:** المواصفات وقرارات التصميم وتقارير التحقق.

## مبادئ التطوير

1. تطوير كل مكوّن في فرع مستقل وفتح Pull Request للمراجعة.
2. الحفاظ على `main` مستقراً وعدم إدخال تغييرات إليه قبل اكتمال المراجعة والموافقة.
3. اعتماد وضع Preview والبيانات التجريبية عند اختبار التكاملات.
4. عدم تضمين مفاتيح API أو كلمات المرور أو المفاتيح الخاصة في المستودع أو السجلات.
5. عدم تنفيذ معاملات بلوكتشين أو نشر عقود أو نشر إنتاجي ضمن الاختبارات الاعتيادية.
6. توثيق نتائج الاختبارات بوضوح، مع الفصل بين ما تم التحقق منه وما لم يُختبر بعد.

## حالة التنفيذ

هذا الملف يعرّف الهيكل والغرض فقط. لا يعني وجود أي تكامل أو خدمة أو عقد ذكي أنه مكتمل أو متصل أو منشور. يجب إثبات كل حالة من خلال ملفات التنفيذ ونتائج الاختبارات وسجلات CI ذات الصلة.

## خريطة المجلدات

المسارات أدناه **هيكل مقترح مستقبلي**، وجميعها نسبية إلى هذا المجلد `projects/sinda-platform/`، وليست تأكيداً على أن المجلدات أو مكوناتها قد أُنشئت بالفعل:

```text
projects/
└── sinda-platform/
    ├── README.md
    ├── core/             # خدمات المنصة الأساسية وواجهات API
    ├── smart-contracts/  # مصادر العقود الذكية واختباراتها
    ├── blockchain/       # موصلات الشبكات وأدوات القراءة والتحقق
    ├── ai-agents/        # الوكلاء ومحركات الذكاء الاصطناعي
    ├── investment/       # التحليلات وبيانات الأسواق
    ├── security/         # المصادقة والصلاحيات والحوكمة
    ├── tests/            # اختبارات التكامل والجودة المشتركة
    └── docs/             # المواصفات وقرارات التصميم والتقارير
```

يُنشأ كل مجلد عند اعتماد نطاقه ووجود ملفات فعلية له، ثم تُحدّث هذه الخريطة وروابط المكونات وفق الحالة المثبتة. لا تُنشأ مجلدات فارغة لمجرد مطابقة الرسم التخطيطي.

## المساهمة والمراجعة

يجب أن يوضح كل Pull Request نطاق التغيير، والملفات المتأثرة، والاختبارات المنفذة، والمخاطر المعروفة، وأي خطوات تشغيل مطلوبة. لا يُعد فتح Pull Request موافقة على الدمج أو النشر.
